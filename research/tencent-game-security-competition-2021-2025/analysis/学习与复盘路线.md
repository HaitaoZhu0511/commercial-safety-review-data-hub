# 学习与复盘路线

这条路线面向授权实验和防守研究，不以绕过真实商业游戏保护为目标。

## 12 周路线

### 第 1—2 周：基础与边界

- 复习操作系统、进程/线程、内存、文件格式与基础汇编；
- 熟悉赛事规则、知识产权、隐私和负责任披露边界；
- 只使用自建 Toy Program、官方题包或明确授权样本。

产物：实验环境清单、样本来源表、哈希清单、安全边界说明。

### 第 3—4 周：静态与动态证据

- 在隔离环境中分析 Toy Binary/APK 的结构和运行事件；
- 学习把观察写成“证据”，而不是只记录最终答案；
- 建立样本、模块、函数、运行事件和分析结论的关联 ID。

产物：分析报告模板、证据 Schema、可重复的环境说明。

### 第 5—6 周：行为序列与标签治理

- 用虚构行为数据练习用户/会话/事件三级建模；
- 处理标签延迟、标签噪声和类别不均衡；
- 比较随机切分、按主体切分和按时间切分的结果差异。

产物：数据卡、标签卡、泄漏检查、基线模型报告。

### 第 7—8 周：跨域评测

- 构造跨语言、跨版本或跨模拟游戏数据；
- 做 leave-one-domain-out 测试；
- 同时报告 Precision、Recall、FPR、校准与置信区间。

产物：分群指标、漂移报告、失败样本集。

### 第 9—10 周：人机协同与审核中台

- 将模型输出转为案件证据，不直接转成封禁；
- 设计人工复核、二审、申诉和恢复流程；
- 保存规则、模型、阈值、数据和人工决定版本。

产物：任务/决定/证据协议、状态机、权限矩阵。

### 第 11—12 周：上线与复盘

- 用历史脱敏数据做离线回放和影子运行；
- 设计灰度、护栏、Kill Switch 和回滚演练；
- 将 badcase 转成回归 Case，而不是停留在复盘文档。

产物：Release Card、Eval Report、事故演练记录和改进清单。

## 复盘模板

每道公开赛题或研究样本按以下结构记录：

```text
1. 来源与授权：URL、许可证、获取时间、哈希
2. 风险对象：文件、客户端、文本、视频、行为序列
3. 任务定义：输入、输出、主体、时间窗口
4. 数据问题：噪声、缺失、偏差、泄漏、跨域
5. 证据设计：哪些观察能支撑结论
6. 方法基线：最简单可复现方案
7. 评估设计：切分、指标、置信区间、失败切片
8. 生产差距：实时性、成本、隐私、解释、申诉
9. 安全边界：哪些内容不得迁移到真实业务
10. 回归资产：新增 Case、规则或监控项
```

## 推荐指标

| 领域 | 指标 |
| --- | --- |
| 检测质量 | Precision、Recall、FPR、FNR、PR-AUC、校准误差 |
| 跨域泛化 | 各语言/游戏/版本最差分群表现、域间差值 |
| 数据质量 | 标签一致率、伪标签覆盖率、泄漏检查通过率 |
| 运营质量 | 人审率、分歧率、申诉翻案、风险存续 |
| 工程质量 | P95 延迟、可用率、回滚时间、证据完整率 |

严重风险与关键分群必须单独设置护栏，不能被总体平均分掩盖。

## 资料使用优先级

1. 官方年度主页与赛题入口；
2. 官方最终结果和专家点评；
3. 有明确许可证、环境和复现说明的参赛仓库；
4. 无许可证的公开方案只阅读思路；
5. 无法确认来源、篡改状态或授权的数据不进入训练与评测资产。
