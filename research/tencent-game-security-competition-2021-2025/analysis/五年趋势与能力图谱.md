# 五年趋势与能力图谱

## 赛道演化

| 年份 | PC | Android | 机器学习 | 其他 |
| --- | --- | --- | --- | --- |
| 2021 | 客户端分析基础 | 客户端分析基础 | 大规模行为序列、标签噪声 | NLP 独立赛道 |
| 2022 | 客户端安全 | 客户端安全 | PE 恶意文件、MOBA 预测 | 和平精英合作方向 |
| 2023 | 静态/动态与程序行为 | 混淆、调试与算法理解 | 少标签、大量无标签、视频特征 | 三主线定型 |

| 2025 | VT/EPT、虚拟化边界 | 防御方案、客户端与行为证据 | 跨游戏行为泛化 | 机器学习单轮评审 |

## 趋势一：PC 从二进制逆向走向系统与虚拟化

五年稳定保留 PC 赛道。公开点评体现的能力层级可以概括为：

```text
程序结构与算法
  → 静态/动态分析
  → 混淆、反调试与保护识别
  → Windows 内核与驱动边界
  → VT/EPT 等硬件虚拟化场景
```

真正适合生产的数据化方向是“多层证据图”：样本、模块、进程、驱动、内存、内核事件、虚拟化状态、游戏会话和服务器行为要使用统一 ID 关联。任何单点特征都可能被适配或产生兼容性误报。

## 趋势二：Android 从破解挑战转向开发者防御

2023—2024 的公开点评强调混淆、调试、完整性和具体游戏风险场景；2025 明确强调从开发者角度提出防御策略。

能力模型因此从“能分析样本”升级为：

- 能定义客户端信任边界；
- 能说明每个信号的攻击面与失效模式；
- 能把客户端证据与服务器行为交叉验证；
- 能评估兼容性、性能、误报和版本漂移；
- 能用灰度、回滚和申诉处理错误处置。

## 趋势三：机器学习问题越来越接近真实数据

| 数据难题 | 对应年份 | 生产治理要求 |
| --- | --- | --- |
| 超大规模、事件/用户标签错位 | 2021 | 主体与事件分层、时间标签、分块计算 |
| 文件家族与静态特征 | 2022 | 家族级切分、变种鲁棒性、证据解释 |
| 小标注、大量无标注 | 2023 | 伪标签分层、弱监督评估、数据泄漏检查 |
| 多语言与合成标注 | 2024 | 语言切片、翻译血缘、合成数据置信度 |
| 跨游戏与数值空间变化 | 2025 | 跨域验证、游戏留一法、漂移和冷启动 |

五年趋势不是简单的“传统模型 → 大模型”。更准确的描述是：风险对象和数据分布不断跨域，评估必须从随机切分走向时间、主体、家族、语言和游戏维度的严格隔离。

## 趋势四：赛事逐步连接真实业务和产教体系

- 2022 引入具体游戏合作方向；
- 2023 起公开强调腾讯专家与高校评委结合；
- 2024—2025 扩大高校学院支持；
- 最终结果页开始提供更详细的专家点评，把排名转成能力反馈。

这使赛事同时承担人才识别、技术教育和业务问题抽象三种作用。但赛题是受控环境，不能代表生产系统的全部复杂性。

## 能力图谱

### L1 基础

- 操作系统、计算机组成、网络与数据结构；
- C/C++、Java/Kotlin、Python；
- 二进制格式、汇编、调试器和基础密码学；
- 统计学习、特征工程、验证集和评价指标。

### L2 场景分析

- Windows/Android 客户端结构与可信边界；
- 静态、动态和行为证据结合；
- 用户、设备、对局和事件序列建模；
- 文本、视频、文件和时序等多模态数据处理。

### L3 对抗与泛化

- 理解混淆、保护、内核和虚拟化带来的观测难题；
- 识别标签噪声、伪标签偏差和数据泄漏；
- 跨语言、跨游戏、跨版本和跨设备验证；
- 设计对抗漂移与失败降级方案。

### L4 生产治理

- 版本、证据、权限、审计和职责分离；
- 灰度、影子、回滚与 Kill Switch；
- 误报、漏报、风险存续和申诉恢复；
- 数据最小化、保留期限、隐私和合规。

赛事主要覆盖 L1—L3；本仓库的数据审核中台补足 L4。

## 对安全审核数据 Agent 的直接设计建议

### 建立四类实体

```text
Artifact：binary / package / text / video / telemetry
Observation：static_feature / runtime_event / sequence / model_score
Decision：risk_label / confidence / reason / policy_version
Action：review / restrict / block / restore / appeal
```

### Agent 可以做

- 汇总跨模态证据并生成带引用的案件摘要；
- 查询历史相似 badcase、规则和模型版本；
- 发现跨游戏/语言/版本指标漂移；
- 生成评测 Case、回归清单和灰度观察建议。

### Agent 不应自主做

- 执行永久封禁、资金动作或公开披露；
- 根据单一模型分数判定外挂；
- 把未授权题包、参赛作品或用户数据加入训练集；
- 生成用于绕过真实游戏安全系统的操作方案。

## 证据局限

- 2021—2022 官方结果页缺少详细技术点评，部分技术分析来自公开参赛仓库。
- 历史 HTML 页面仍可访问，但部分直链题包受到防盗链、权限或迁移影响。
- 公开 GitHub 方案只是个别参赛者方法，不能代表获奖最优解，更不能代表腾讯内部方案。
- 各年份的指标、数据切分和任务定义不完全一致，不应直接比较分数高低。
