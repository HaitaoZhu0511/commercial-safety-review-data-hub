# 腾讯游戏安全技术竞赛：2021—2025 资料与分析

本目录整理五个完整自然年（2021—2025）腾讯游戏安全技术竞赛的公开材料，并分析赛道、命题与能力要求的演化。2026 年赛事尚不属于本次完整五年样本，只在后续更新时单独跟踪。

> 范围说明：“腾讯游戏安全技术竞赛”与 0CTF/TCTF 不是同一赛事体系。本目录以腾讯游戏安全中心官网连续保留的第六至第十届赛事为唯一统计主线，不把其他腾讯相关比赛混入趋势数据。

## 安全与版权边界

- 只收录官方页面、官方题包入口和公开 GitHub 方案链接，不重新托管第三方源码、赛事二进制或数据集。
- 部分题包可能包含可执行文件，只能在授权、隔离的实验环境中研究；本目录不提供绕过商业游戏保护或制作外挂的操作步骤。
- GitHub 公开不等于允许复制。无许可证仓库仅作阅读索引，不能直接复用代码或数据。
- 本文分析的是公开赛题和专家点评，不能据此推断腾讯内部检测逻辑、阈值、样本库或生产架构。

```text

race-pre.htm            初赛说明与题包下载入口
race-pre-result.htm     初赛晋级结果
```

目录没有复制参赛者姓名、学校和个人信息；分析只聚焦赛题、方法与人才能力。

## 总结：五年里真正稳定的三条主线

### 1. PC 客户端安全

持续考察二进制理解、静态/动态分析、混淆与反调试识别、Windows 内核机制；2025 年进一步进入 VT/EPT 等虚拟化对抗。它对应的是从应用层分析走向内核与硬件辅助虚拟化的能力升级。

### 2. Android 客户端安全

从 APK/Native 分析、反调试和完整性保护，逐步转向真实游戏场景中的风险识别与防护设计。2025 年公开点评明显强调“站在游戏开发者角度提出防御方案”，而不只是完成逆向任务。

### 3. 机器学习安全

从 2021 年大规模、有标签噪声的行为序列检测，经历 2022 年 PE 恶意文件识别、2023 年小标注/大未标注视频数据、2024 年跨语言恶意文本，到 2025 年跨游戏行为序列泛化。主线不是模型越来越大，而是数据越来越贴近真实业务中的脏、偏、稀疏和跨域问题。

## 对当前数据 Agent 项目的启示

这些赛事材料可以转成安全审核数据中台的四类资产：

- **风险本体**：外挂、恶意文件、异常行为、恶意文本、跨游戏泛化等风险标签；
- **信号目录**：二进制静态特征、运行行为、时序统计、多语言文本和客户端完整性信号；
- **评测集**：跨年份、跨游戏、跨语言、标签噪声和小样本 Case；
- **运营闭环**：模型召回之外，同时记录误报、泛化、漂移、证据和人工复核。

不能直接把竞赛方案当成生产方案。赛事通常给定明确目标、固定数据和离线指标，而生产风控还需要实时性、对抗更新、隐私、成本、可解释、申诉和灰度回滚。
